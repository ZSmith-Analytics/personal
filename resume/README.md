# Resume

Source copy currently matches the Google Doc “Resume 9/2026”. Re-copy from the HTML after edits if you want Docs and this file to stay in sync.

## Paste into Google Docs

1. Open `zack-smith-resume.html` in a browser (double-click, or `python3 -m http.server` from this folder).
2. Select all (`Cmd+A`) and copy (`Cmd+C`).
3. In Google Docs, use **Edit → Paste** (or `Cmd+V`), not Paste without formatting.
4. Set page to **Letter**, margins about **0.7–0.85 in**.
5. If the right-aligned locations wrap oddly, select each job header line and set it to a single paragraph, or put the location on the same line after a tab.

Headings, gold rules, bold/italic, and bullets usually survive the paste. Fonts land as Georgia (body) and Arial (name and section labels).

## Edit later

Change the HTML, refresh the browser, copy again. Keep inline `style="..."` attributes if you want Google Docs to keep the look; a separate stylesheet often does not paste.
